## 3. 页面样式规范

### 3.1 布局

- 使用 Element Plus 的 `el-container` 布局
- 左侧菜单 + 顶部导航 + 右侧内容区
- 支持菜单折叠

### 3.2 表格

- 使用 `el-table` + `el-pagination`
- 支持多条件筛选
- 状态字段使用 `el-tag` 颜色标签

### 3.3 表单

- 使用 `el-dialog` 弹窗表单
- 支持表单校验
- 提交时显示 loading

### 3.4 颜色规范

| 状态 | 颜色 |
|------|------|
| 成功/启用/已完成 | success (绿色) |
| 警告/充电中/待处理 | warning (橙色) |
| 危险/故障/已驳回 | danger (红色) |
| 信息/停用/已关闭 | info (灰色) |
| 主要/进行中 | primary (蓝色) |
