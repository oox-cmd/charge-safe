### 1.2 各区域设计

#### 顶部标题区

| 项目 | 说明 |
|------|------|
| 内容 | 系统名称、当前时间、当前社区、登录角色 |
| 样式 | 深色背景、居中标题、右侧时间显示 |
| 数据来源 | 前端状态 + userStore |

#### 左侧统计区

| 组件 | 数据来源 | 图表类型 | 说明 |
|------|----------|----------|------|
| 端口状态分布 | /api/ports/statistics | ECharts 环形图 | 按状态颜色区分 |

| 组件 | 数据来源 | 展示方式 | 说明 |

| 设备状态展示 | /api/devices | 状态标签 | 每个设备显示端口状态 |

#### 右侧列表区

| 组件 | 数据来源 | 展示方式 | 说明 |
|------|----------|----------|------|
| 实时告警滚动 | /api/simulator | 滚动列表 | 故障端口红色强调 |
| 工单列表 | /api/repair-tickets | 滚动列表 | 待处理工单 |
| 隐患列表 | /api/hazards | 滚动列表 | 待整改隐患 |

#### 底部趋势区

| 组件 | 数据来源 | 图表类型 | 说明 |
|------|----------|----------|------|
| 预约/订单趋势 | /api/orders | ECharts 折线图 | 今日预约、订单数量 |
| 故障变化趋势 | /api/statistics | ECharts 折线图 | 故障端口数量变化 |

## 2. 第二阶段：简化 3D 场景

### 2.1 设计思路

使用简单几何体表达车棚和充电桩，不依赖复杂模型。

### 2.2 场景元素

| 元素 | 表达方式 | 说明 |
|------|----------|------|
| 车棚 | 长方体 | 半透明材质 |
| 充电桩 | 小长方体 | 灰色材质 |
| 端口 | 小球体 | 颜色映射状态 |
| 地面 | 平面 | 深色材质 |

### 2.3 交互设计

| 交互 | 说明 |
|------|------|
| 点击端口 | 弹出详情卡片（编号、状态、订单、工单） |
| 悬停高亮 | 鼠标悬停时端口发光 |
| 视角切换 | 支持俯视、侧视、自由视角 |

### 2.4 技术选型

- **Three.js** 或 **TresJS**（Vue3 特化型 3D 框架）
- 模型格式：GLB/GLTF（后续导入）
- 性能优化：Draco 压缩、LOD

### 2.5 参考项目

| 项目 | 参考内容 |
|------|----------|
| smartPark-3D | 智慧园区 3D 场景 |
| 3d-datacenter | 设备状态、告警交互 |
| 图扑光储充 | 3D + 大屏结合 |

## 3. 第三阶段：模型增强

### 3.1 目标

1. 导入真实充电桩 3D 模型
2. 添加动效（故障闪烁、充电动画）
3. 完善交互（点击、拖拽、漫游）

### 3.2 注意事项

1. 模型来源必须合法（CC0 或购买授权）
2. 模型文件必须经过 Draco 压缩
3. 控制模型数量，避免性能问题
4. 先在 PC 端测试，再考虑移动端适配
