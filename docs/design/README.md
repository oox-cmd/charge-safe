## 文档用途说明

1. **source-code-analysis.md** - 解决"当前项目有什么、缺什么"的问题
2. **image-reference-analysis.md** - 解决"参考截图能借鉴什么"的问题
3. **refactor-and-architecture-plan.md** - 解决"要不要重构、怎么重构"的问题
4. **backend-design.md** - 解决"后端模块怎么划分、接口怎么设计"的问题
5. **database-design.md** - 解决"数据库表怎么设计、状态机怎么流转"的问题
6. **frontend-page-design.md** - 解决"前端页面怎么布局、组件怎么复用"的问题
7. **miniapp-page-design.md** - 解决"小程序端怎么做、优先实现哪些页面"的问题
8. **dashboard-visual-design.md** - 解决"大屏怎么做、3D怎么做"的问题
9. **next-stage-tasks.md** - 解决"下一步谁做什么、先做什么"的问题

## 使用说明

1. 先阅读 source-code-analysis.md 了解项目现状
2. 再阅读 refactor-and-architecture-plan.md 了解重构建议
3. 然后根据角色阅读对应的设计文档
4. 最后查看 next-stage-tasks.md 了解下一步任务
