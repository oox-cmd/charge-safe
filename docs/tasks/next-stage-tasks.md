## 6. 风险说明

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| 数据库迁移失败 | 后端无法启动 | 先备份数据，再执行迁移 |
| 前端页面冲突 | 功能异常 | 使用 Git 分支开发 |
| 小程序审核不通过 | 无法上线 | 先做 H5 预览版本 |
| 大屏性能问题 | 展示效果差 | 控制数据量，优化渲染 |
