## 阶段 3：统计分析页重构

**目标：** 让统计页回答真实业务问题

**涉及文件：** `charge-safe-admin/src/views/statistics/Index.vue`

### 3.1 顶部指标卡片

**当前问题：** 8 个数字卡片，没有业务解释

**重构方案：**
- 保留 4 个核心指标：端口总数、空闲端口、充电中、故障端口
- 每个指标显示环比变化（与昨天对比）
- 添加"今日预约"和"今日订单"指标
- 添加"待处理工单"和"待整改隐患"指标（红色强调）

**验收标准：**
- 指标有业务意义
- 显示趋势变化
- 异常指标有视觉强调

### 3.2 端口状态分布图

**当前问题：** 只是饼图，没有回答"是否正常"

**重构方案：**
- 改为环形图，中心显示总数
- 颜色使用端口状态规范色
- 添加阈值线：如果故障端口超过 10%，显示红色警告
- 添加"空闲率"指标

**验收标准：**
- 能快速判断端口状态是否正常
- 故障端口有视觉警告

### 3.3 车棚利用率图

**当前问题：** 只是柱状图，没有回答"哪些车棚最紧张"

**重构方案：**
- 按利用率排序
- 利用率超过 80% 的车棚标红
- 显示每个车棚的空闲端口数
- 添加利用率阈值线

**验收标准：**
- 能快速判断哪些车棚最紧张
- 高利用率车棚有视觉警告

### 3.4 订单趋势图

**当前问题：** 只是折线图，没有回答"是否增长"

**重构方案：**
- 显示近 7 天订单数量
- 显示完成订单数量
- 添加趋势线
- 显示环比增长率

**验收标准：**
- 能判断订单趋势是否正常
- 显示增长或下降趋势

### 3.5 工单积压情况

**当前问题：** 没有展示工单积压情况

**重构方案：**
- 添加工单状态分布图（柱状图）
- 显示待受理、处理中、待验收数量
- 待受理超过 5 个显示红色警告
- 添加平均处理时长

**验收标准：**
- 能判断工单是否积压
- 积压工单有视觉警告

### 3.6 隐患整改情况

**当前问题：** 没有展示隐患整改情况

**重构方案：**
- 添加隐患状态分布图（饼图）
- 显示待处理、整改中、待复查数量
- 待处理超过 3 个显示红色警告
- 添加整改完成率

**验收标准：**
- 能判断隐患是否及时整改
- 未整改隐患有视觉警告

## 阶段 4：大屏整页重构

**目标：** 把当前大屏改成真正的"社区充电安全态势大屏"

**涉及文件：** `charge-safe-admin/src/views/bigscreen/Index.vue`

### 4.1 整体布局

**当前问题：** 科技蓝模板，无业务特色

**重构方案：**
```
[顶部：系统名称 + 当前时间 + 当前社区]
[左侧：端口状态分布 + 车棚利用率]
[中间：端口状态矩阵]
[右侧：告警列表 + 工单列表 + 隐患列表]
[底部：订单趋势 + 故障趋势]
```

### 4.2 中间主视觉

**当前问题：** 端口状态矩阵是模拟数据

**重构方案：**
- 对接后端 `/api/statistics/port-status` 接口
- 按社区→车棚→设备→端口展示
- 端口用色块表示状态
- 点击或悬浮显示端口详情
- 第一版用 CSS 实现，不做 3D

**验收标准：**
- 显示真实端口状态
- 色块颜色符合规范
- 点击有交互反馈

### 4.3 左侧统计区

**当前问题：** 图表没有业务意义

**重构方案：**
- 端口状态环形图：显示各状态端口数量
- 车棚利用率柱状图：显示各车棚利用率
- 核心指标卡片：端口总数、空闲、充电中、故障

**验收标准：**
- 图表有业务意义
- 颜色符合规范

### 4.4 右侧告警区

**当前问题：** 告警列表是模拟数据

**重构方案：**
- 实时告警列表：对接 `/api/hazards` 接口
- 待处理工单列表：对接 `/api/repair-tickets` 接口
- 待整改隐患列表：对接 `/api/hazards` 接口
- 滚动展示
- 严重告警红色强调

**验收标准：**
- 显示真实数据
- 严重告警有视觉强调

### 4.5 底部趋势区

**当前问题：** 趋势图没有业务意义

**重构方案：**
- 订单趋势折线图：近 7 天订单数量
- 故障趋势折线图：近 7 天故障数量
- 颜色符合规范

**验收标准：**
- 能看出趋势变化
- 颜色符合规范

### 4.6 视觉规范

**必须遵守：**
- 背景：#0a1a3a（深蓝）
- 面板背景：rgba(255, 255, 255, 0.05)
- 面板边框：rgba(64, 158, 255, 0.2)
- 字体：标题白色 16px，正文 #a0aec0 14px
- 端口状态颜色：IDLE #22c55e、CHARGING #f59e0b、FAULT #ef4444

**禁止：**
- ❌ 发光边框
- ❌ 渐变文字
- ❌ 3D 效果
- ❌ 粒子效果

## 阶段 5：小程序体验重构

**目标：** 让小程序像居民真实会用的产品

### 5.1 首页重构

**当前问题：** 不知道用户第一步该干什么

**涉及文件：** `charge-safe-miniapp/src/pages/index/index.vue`

**重构方案：**
```
[顶部：用户信息 + 消息入口]
[主操作卡片：找车棚 → 看空闲端口 → 预约]
[快捷入口：我的预约、充电订单、设备报修]
```

- 显示车棚统计：总端口、空闲、充电中、故障

**验收标准：**
- 端口状态一目了然
- 空闲端口可点击预约
- 显示车棚统计信息

### 5.3 预约确认重构

**涉及文件：** `charge-safe-miniapp/src/pages/reservation/confirm.vue`
