## 过程记录与归档

- [`process/logs/`](process/logs/) 保存已实施批次的事实记录，不作为当前功能清单。
- [`archive/`](archive/) 保存调研、旧审计、旧设计与已完成计划；这些材料可追溯，但不得覆盖当前状态文档。

不要从归档文档复制启动命令、账号、接口状态或待办结论；需要确认时应回到源码和上方四份当前文档。
