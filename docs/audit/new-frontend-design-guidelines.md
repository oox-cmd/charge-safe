# ChargeSafe 新前端设计规范

> 制定时间：2026-07-04
> 依据：ui-ux-pro-max skill + frontend-design skill
> 目标：建立统一的前端设计规范，消除 AI 味，提升产品质感

---

## 1. 总体风格定位

### 管理端：成熟、干净、稳定的运维后台

**风格关键词：** 专业、克制、高效、可靠

**设计理念：**
- 以表格、状态、流程、操作为核心
- 不追求炫酷，追求实用
- 页面统一，减少学习成本
- 重点突出"社区、车棚、设备、端口、工单、隐患"

**参考风格：** Element Plus 后台管理系统，但更克制、更统一

### 大屏：克制的深色运维风

**风格关键词：** 专业、克制、语义化、可读

**设计理念：**
- 不是赛博模板，不是泛泛科技风
- 必须围绕社区充电安全
- 所有颜色都要服务状态语义
- 中间必须是端口状态矩阵或社区充电安全态势图

**参考风格：** Grafana、Datadog 等运维监控大屏

### 小程序：轻量、清楚、易用

**风格关键词：** 简洁、直观、高效、友好

**设计理念：**
- 居民真实使用
- 首页动作明确
- 操作流程顺畅
- 状态清晰易懂

**参考风格：** 美团、支付宝等生活服务小程序

## 2. 管理端规范

### 2.1 页面标题

**规范：**
- 使用面包屑导航：首页 > 模块名 > 页面名
- 页面标题使用 h2 或 el-page-header
- 标题文案简洁明了，不要堆砌形容词

**示例：**
```
首页 > 充电业务 > 充电订单
```

**禁止：**
- ❌ "智能充电订单管理系统"
- ❌ "充电业务数据可视化平台"

### 2.2 搜索区

**规范：**
- 搜索区放在表格上方
- 使用 el-form inline 布局
- 搜索字段不超过 4 个
- 提供"查询"和"重置"按钮
- 支持回车查询

**布局：**
```
[输入框] [下拉框] [日期范围] [查询] [重置]
```

**示例字段：**
- 用户管理：用户名、手机号、状态
- 充电订单：订单号、状态、日期范围
- 维修工单：工单号、状态、维修人员

### 2.3 表格

**规范：**
- 使用 el-table stripe（斑马纹）
- 列宽合理分配，重要列更宽
- 操作列固定在右侧
- 长文本使用 show-overflow-tooltip
- 空数据使用 el-empty

**列宽建议：**
- ID：80px
- 编号/工单号：150px
- 状态：100px
- 时间：180px
- 操作：根据按钮数量调整

### 2.4 分页

**规范：**
- 分页放在表格下方，右对齐
- 显示总数：`共 X 条`
- 支持切换每页条数：10、20、50
- 使用 el-pagination

**布局：**
```
共 100 条  [<] [1] [2] [3] [>]  [10条/页]
```

### 2.5 操作按钮

**规范：**
- 主要操作使用 el-button type="primary"
- 危险操作使用 el-button type="danger"
- 链接操作使用 el-button link
- 操作列按钮不超过 4 个
- 超过 4 个使用"更多"下拉菜单

**主次分明：**
- 主要操作：新增、保存、提交
- 次要操作：编辑、查看详情
- 危险操作：删除、驳回

### 2.6 状态标签

**规范：**
- 使用 el-tag
- 颜色统一，不要随意更换
- 文案简洁，2-4 个字

**颜色规范：**
| 状态类型 | 颜色 | 示例 |
|----------|------|------|
| 成功/完成 | success (绿色) | 已完成、已通过、已关闭 |
| 进行中 | primary (蓝色) | 处理中、整改中 |
| 待处理 | warning (橙色) | 待受理、待复查、待处理 |
| 异常/失败 | danger (红色) | 已驳回、已取消、故障 |
| 默认/禁用 | info (灰色) | 已禁用、已停用 |

### 2.7 弹窗

**规范：**
- 使用 el-dialog
- 宽度 500px-700px
- 标题简洁明了
- 表单使用 el-form label-width="80px"
- 底部按钮：取消 + 确定

**布局：**
```
[标题]
[表单内容]
[取消] [确定]
```

### 2.8 详情抽屉

**规范：**
- 使用 el-drawer
- 宽度 400px-600px
- 显示详细信息
- 支持关闭

### 2.9 空状态

**规范：**
- 使用 el-empty
- 提示文案："暂无数据"
- 可选：提供"刷新"或"新增"按钮

### 2.10 Loading 状态

**规范：**
- 表格使用 v-loading
- 按钮使用 :loading
- 页面使用 v-loading fullscreen

### 2.11 错误状态

**规范：**
- 使用 ElMessage.error
- 错误文案具体明确
- 不要显示技术细节

**示例：**
- ✅ "获取数据失败，请稍后重试"
- ❌ "Request failed with status code 500"

### 2.12 页面留白

**规范：**
- 页面内边距：20px
- 卡片间距：20px
- 表格上方间距：20px
- 分页上方间距：20px

### 2.13 信息层级

**规范：**
- 一级信息：页面标题、主要数据
- 二级信息：搜索区、表格
- 三级信息：分页、操作按钮
- 使用间距和颜色区分层级

## 3. 大屏规范

### 3.1 背景

**规范：**
- 使用深色背景：#0a1a3a 或 #0d1f3c
- 不要使用渐变背景
- 不要使用网格背景
- 保持简洁

### 3.2 面板

**规范：**
- 面板背景：rgba(255, 255, 255, 0.05)
- 面板边框：rgba(64, 158, 255, 0.2)
- 面板圆角：8px
- 面板内边距：16px

**禁止：**
- ❌ 发光边框
- ❌ 渐变边框
- ❌ 阴影效果

### 3.3 字体

**规范：**
- 标题：16px，白色，加粗
- 正文：14px，#a0aec0
- 数据：24px，白色，加粗
- 单位：12px，#718096

### 3.4 图表

**规范：**
- 使用 ECharts
- 颜色使用状态语义色
- 不要使用渐变色
- 标签简洁明了

**禁止：**
- ❌ 3D 效果
- ❌ 渐变色
- ❌ 发光效果

### 3.5 状态颜色

**必须使用以下颜色：**
| 状态 | 颜色 | 色值 |
|------|------|------|
| IDLE (空闲) | 绿色 | #22c55e |
| RESERVED (已预约) | 蓝色 | #3b82f6 |
| CHARGING (充电中) | 橙色 | #f59e0b |
| FAULT (故障) | 红色 | #ef4444 |
| MAINTENANCE (维修中) | 灰色 | #94a3b8 |
| DISABLED (停用) | 浅灰 | #c0c4cc |
| OFFLINE (离线) | 浅灰 | #c0c4cc |

### 3.6 告警展示

**规范：**
- 告警列表在右侧
- 滚动展示
- 严重告警红色强调
- 显示时间

### 3.7 中间主视觉

**必须是以下之一：**
1. 端口状态矩阵：按社区→车棚→设备→端口展示
2. 社区充电安全态势图：展示各车棚状态

**要求：**
- 端口用色块表示状态
- 点击或悬浮显示端口详情
- 第一版用 CSS 实现，不做 3D

### 3.8 动效限制

**规范：**
- 数据更新时使用数字滚动
- 告警列表使用滚动
- 不要使用过度动效

**禁止：**
- ❌ 粒子效果
- ❌ 3D 旋转
- ❌ 复杂动画

### 3.9 1920×1080 适配

**规范：**
- 使用 CSS scale 做大屏适配
- 基准宽度 1920px
- 基准高度 1080px

### 3.10 业务讲解路径

**答辩时的讲解顺序：**
1. 中间：端口状态矩阵，展示各车棚端口使用情况
2. 左侧：端口状态分布、车棚利用率
3. 右侧：实时告警、待处理工单、待整改隐患
4. 底部：订单趋势、故障趋势

## 4. 小程序规范

### 4.1 首页结构

**必须突出的主路径：**
1. 找车棚
2. 看空闲端口
3. 预约
4. 开始充电

**布局：**
```
[顶部：用户信息 + 消息入口]
[主操作：找车棚 → 看空闲端口 → 预约]
[快捷入口：我的预约、充电订单、设备报修]
[最近订单列表]
```

### 4.2 车棚卡片

**规范：**
- 显示车棚名称
- 显示地址
- 显示空闲端口数
- 显示总端口数
- 点击进入详情

### 4.3 端口状态

**必须使用色块矩阵：**
- 空闲：绿色 (#22c55e)
- 已预约：蓝色 (#3b82f6)
- 充电中：橙色 (#f59e0b)
- 故障：红色 (#ef4444)
- 维修中：灰色 (#94a3b8)

**交互：**
- 点击空闲端口：进入预约确认
- 点击其他状态：显示详情

### 4.4 预约流程

**完整流程：**
1. 选择车棚
2. 选择端口
3. 确认预约
4. 显示预约成功
5. 返回首页或订单页

**要求：**
- 对接后端接口
- 显示加载状态
- 处理错误情况

### 4.5 报修表单

**规范：**
- 选择设备或端口
- 填写故障类型
- 填写故障描述
- 图片上传（可选）
- 提交报修

### 4.6 按钮大小

**规范：**
- 主要按钮：高度 88rpx，圆角 16rpx
- 次要按钮：高度 72rpx，圆角 12rpx
- 文字按钮：无高度限制

### 4.7 移动端间距

**规范：**
- 页面内边距：20rpx-30rpx
- 卡片间距：20rpx
- 卡片内边距：30rpx
- 列表项间距：16rpx

### 4.8 用户提示

**规范：**
- 使用 uni.showToast
- 成功：icon: 'success'
- 失败：icon: 'none'
- 加载：uni.showLoading

### 4.9 空状态

**规范：**
- 显示提示文案："暂无数据"
- 可选：显示图标
- 可选：提供操作按钮

### 4.10 错误提示

**规范：**
- 使用 uni.showToast
- 文案具体明确
- 不要显示技术细节

## 6. 文案规范

### 6.1 不推荐文案示例

| 场景 | 不推荐 | 推荐 |
|------|--------|------|
| 大屏标题 | 社区充电安全态势大屏 | 社区充电安全监控 |
| 统计标题 | 智能充电数据分析 | 充电数据统计 |
| 按钮文案 | 立即体验 | 开始充电 |
| 空状态 | 暂无数据 | 暂无充电记录 |
| 错误提示 | 系统异常，请联系管理员 | 获取数据失败，请稍后重试 |

### 6.2 推荐文案示例

| 场景 | 推荐文案 |
|------|----------|
| 页面标题 | 充电订单、维修工单、安全隐患 |
| 按钮文案 | 新增、编辑、删除、查询、重置 |
| 状态文案 | 空闲、已预约、充电中、故障 |
| 操作文案 | 接单、完成维修、验收通过、驳回 |

### 6.3 按钮文案规范

**主要操作：**
- 新增、保存、提交、确定、查询

**次要操作：**
- 编辑、查看详情、刷新

**危险操作：**
- 删除、驳回、取消预约

**链接操作：**
- 查看、编辑、删除

### 6.4 状态文案规范

**充电端口状态：**
- 空闲、已预约、充电中、故障、维修中、停用、离线

**充电订单状态：**
- 充电中、已完成、已结算、已取消、异常结束

**维修工单状态：**
- 待受理、已派单、处理中、待验收、已完成、已关闭、已驳回

**安全隐患状态：**
- 待处理、整改中、待复查、复查通过、复查不通过、已关闭

### 6.5 空状态文案规范

**列表空状态：**
- "暂无充电记录"
- "暂无维修工单"
- "暂无安全隐患"

**搜索空状态：**
- "未找到相关数据"
- "请尝试其他搜索条件"
