# 文档归档

此目录保存调研、阶段审计、设计草案和已完成计划。它们保留决策与过程证据，但内容可能反映旧代码、旧待办或旧技术基线，不能作为当前功能与启动说明。

当前文档入口见 [`../README.md`](../README.md)。

| 目录 | 内容 |
| --- | --- |
| `audits/` | 历史审计、代码核验与 UI 审查 |
| `plans/` | 已完成或被替代的实施计划、路线图与任务拆分 |
| `design/` | 设计草案、页面构想和历史架构分析 |
| `research/` | 大屏、资产和其他专题调研 |
| `team-research/` | 队友调研任务与原始汇总 |
| `process/` | 被替代的过程文档方案 |
