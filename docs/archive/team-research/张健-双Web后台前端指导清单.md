## 2. 核心架构与功能模块交付

### 2.1 双后台架构

| 模块 | 文件 | 状态 |
|---|---|---|
| 权限管理端路由 | `src/router/permission.routes.js` | 已完成 |
| 物业运维端路由 | `src/router/ops.routes.js` | 已完成 |
| 权限管理端 Layout | `src/layouts/PermissionLayout.vue` | 已完成 |
| 物业运维端 Layout | `src/layouts/OpsLayout.vue` | 已完成 |
| 路由守卫与鉴权 | `src/router/index.js`, `src/stores/user.js` | 已完成 |

**登录及路由跳转（核心重构）**：
- **持久化状态防止白屏**：不仅缓存 Token，还将 `roleCode` 和 `userId` 持久化至 localStorage。解决页面刷新后由于状态丢失引起的路由死循环问题。
- **角色定向引流**：`getDefaultPathByRole` 函数配置了所有已知角色的首选落地页（`PLATFORM_ADMIN` 去权限看板，物业去运维看板，居民及未知角色定向兜底去 `/bigscreen`）。
- **权限 API 修复**：后端 `AuthController.java` 补充了 `/api/auth/permissions`，前端获取用户权限不再引发 404 弹窗。

### 2.2 权限管理端与物业运维端（共 25+ 页面）

两端各自独立且隔离的页面树已连通。主要内容：
- **数据统计首页 UI 重构**：使用统一的卡片、阴影和边框规范；升级 ECharts 视觉层，引入平滑折线和渐变区域颜色填充 (areaStyle)；遇到没有数据的统计维度时，使用 `<el-empty>` 空状态组件，避免渲染空坐标轴。
- **统一的分页和高级组件**：全面剥离散落的原生 `el-pagination`，全局统一使用 `CsPagination.vue`。

### 2.3 可视化态势大屏 (BigScreen) 深度重构

为了解决早期大屏层次较单一、素材使用不集中的问题，大屏页面被重构为**多维度交互式态势系统**：
- **剥离业务操作**：移除了大屏中如“一键断电”、“处理工单”等运维按钮，让大屏纯粹回归商业视角的“态势感知与数据展示”。
- **多页签 (Tabs) 切换框架**：将大屏无缝划分为 `总览态势`、`设备监控`、`安全防护` 三个维度。所有动画组件利用 `v-show` 管理生命周期，切换零卡顿。
- **Lottie 高级资产动态注入**：
  - `loading.json`：作为头部 HUD 特效。
  - `station.json`：全息投影在总览页中央/侧边，替代原本死板的大背景。
  - `scooter.json`：在设备页中作为详情卡片反馈。点击“充电中”的端口后渲染对应动效，用于展示端口充电状态。
  - `spark.json`：在设备页中用于故障端口的状态反馈。
  - `success.json`：用于安全态势页的操作反馈。
- **顶部用户菜单调整**：扩展了顶部栏可用横向宽度（至 450px），防止时间被挤压折行。新增带头像的用户下拉菜单，支持一键“返回管理后台”或“退出登录”。

## 3. 已处理问题汇总

| 异常现象 | 处理方案与结果 |
|---|---|
| **路由无限重定向卡死浏览器** | 重写 `getDefaultPathByRole` 使其绝对不返回 `/login`；在 Store 中持久化角色字段；加入 `isFetchingUserInfo` 防止并发死锁。 |
| **登录后提示“该角色无权登录后台”并卡住** | 针对居民/未分配角色账号（如 `resident01`），修改路由引流策略，允许其直接跳转至开放性质的 `/bigscreen`。 |
| **登录成功弹出 404 (permissions)** | 在 Java 后端补齐接口，利用 `menuService.listCurrentUserMenus()` 递归提取返回纯权限码列表。 |
| **后台首页图表空数据异常塌陷** | 前端增加数据阈值判断，无数据则使用 `<el-empty>` 遮罩优雅阻断图表实例的渲染。 |
| **大屏顶部日期和社区名字挤压变形** | 修改 CSS 约束，宽度放大至 `450px`，加入 `white-space: nowrap`，并追加了弹出式用户注销菜单。 |
| 各类事件/定时器内存泄漏 | `onBeforeUnmount` 中已全面清理所有的 `setInterval` 和 `Lottie` 实例，以及 `window` 事件。 |
